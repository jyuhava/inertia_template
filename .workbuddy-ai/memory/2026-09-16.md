# 2026-09-16 — SIAKAD: mobile compact + PWA + tema berwarna

## Konteks
User minta semua halaman (mahasiswa, dosen, admin) di-redesain **compact + standar PWA saat mobile**,
lalu menambahkan: beranda mahasiswa belum proper saat PWA → **boleh pakai warna**.

## Arsitektur frontend (penting)
- Laravel 12 + Inertia + **React 18 (JSX)** + Tailwind 3 + Vite. Bukan Vue (ada sisa file `.vue` lama, tidak dipakai).
- `resources/js/app.jsx` punya `window.route()` — helper route manual (Ziggy juga ada via `@routes`).
- **Semua** halaman memakai `resources/js/Layouts/AdminLayout.jsx` (termasuk mahasiswa & dosen).
- Design system lama: monokrom (hitam/putih/neutral), sudut tajam, label `uppercase tracking-widest`.
  Tiap halaman mendefinisikan komponen lokal `Box` dengan varian `white | gray | dark | black`.
- `resources/css/app.css` punya blok "Global Compact Density System" (padding tabel/input dipaksa compact).

## Yang dikerjakan

### 1. Lapisan CSS mobile (`resources/css/app.css`)
Blok baru "MOBILE RESPONSIVE & COMPACT LAYER":
- `.h-dvh` / `.min-h-dvh` (address bar mobile), `.safe-top` / `.safe-bottom`, `.pb-mobile-nav`
- `.table-scroll`, `.table-scroll--sticky-col` (scroll tabel halus + kolom pertama dipatok)
- `.table-cards` — **tabel jadi daftar kartu di <768px**, label diambil dari `data-label` per `<td>`
- Safety net: `.grid` dengan `grid-cols-3..6` tanpa breakpoint → dipaksa 2 kolom di <640px
- Density compact di <640px (p-5/p-6/p-7/p-8, gap, space-y)
- `.hide-mobile`, `.mobile-only`, `.toolbar-wrap`
- `.flex.justify-between` / `.flex.justify-end` boleh wrap di <768px
- Input `font-size: 16px` di mobile (cegah zoom otomatis iOS), `touch-action: manipulation`

## Catatan lingkungan (JANGAN diulang)
- `npm run build` **gagal di sandbox** karena Vite membaca `.env` (dianggap konten sensitif).
  Trik `mv .env` pernah berhasil sekali, tapi bisa bikin perintah kena SIGTERM dan `.env` tertinggal bernama
  `.env.__tmp_build__` → **selalu cek & pulihkan**. Verifikasi cepat tanpa `.env`: pakai esbuild per file
  (`./node_modules/.bin/esbuild --loader:.jsx=jsx <file> --outfile=/dev/null`).
- `grep` dengan alternasi `\|` di Bash tool sering tidak reliable → pakai tool Grep.
- Vite dev server user berjalan di 5173; `public/hot` ada → Laravel memuat aset dari dev server.
- Backup resources/js sebelum transformasi massal: `/tmp/siakad-backup/js-20260916-144344`.
