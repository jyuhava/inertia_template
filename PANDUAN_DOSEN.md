# 👨‍🏫 PANDUAN PENGGUNAAN SIAKAD UNTUK DOSEN

## 🌐 Akses SIAKAD
Buka browser dan kunjungi: **https://siakad.alwafi.ac.id**

---

## 🔑 1. LOGIN KE SISTEM

### Langkah Login:
1. Di halaman utama, klik tombol **"Login"**
2. Masukkan kredensial yang diberikan admin:
   - **Email/Username**: sesuai yang diberikan admin
   - **Password**: password yang diberikan admin
3. Klik **"Masuk"**
4. Jika berhasil, sistem akan mengarahkan ke dashboard dosen

### ⚠️ Catatan Penting:
- Jika lupa password, hubungi admin akademik
- Pastikan akun Anda sudah diverifikasi dan status aktif

---

## 🏠 2. DASHBOARD DOSEN

Setelah login berhasil, Anda akan melihat **Dashboard Dosen** yang menampilkan:

### Informasi Ringkas:
- **Periode Akademik Aktif**: Semester dan tahun ajaran yang sedang berjalan
- **Total Mata Kuliah**: Jumlah mata kuliah yang diampu
- **Total Mahasiswa**: Total mahasiswa di semua kelas yang diampu
- **Daftar Mata Kuliah**: Ringkasan jadwal mengajar dengan jumlah mahasiswa per kelas

### Navigasi Menu Utama:
- 📋 **Jadwal Mengajar**: Lihat semua jadwal kuliah
- 👥 **Mahasiswa**: Daftar mahasiswa per kelas
- 📊 **Penilaian**: Input dan kelola nilai mahasiswa
- ✅ **Absensi**: Kelola kehadiran mahasiswa

---

## 📋 3. JADWAL MENGAJAR

### 3.1 Mengakses Jadwal
1. Dari dashboard, klik menu **"Jadwal"** atau **"Jadwal Mengajar"**
2. Sistem menampilkan semua mata kuliah yang diampu untuk semester aktif

### 3.2 Informasi Jadwal
Setiap jadwal menampilkan:
- **Nama Mata Kuliah** dan **Kode**
- **SKS** (Satuan Kredit Semester)
- **Hari dan Jam** perkuliahan
- **Ruangan** (jika tersedia)
- **Semester** yang mengambil
- **Kapasitas vs Jumlah Mahasiswa** yang terdaftar
- **Status**: Aktif/Nonaktif

### 3.3 Aksi yang Tersedia
Dari halaman jadwal, Anda dapat:
- 👥 **Lihat Mahasiswa**: Daftar mahasiswa yang mengambil mata kuliah
- 📊 **Input Penilaian**: Masuk ke halaman penilaian
- ✅ **Kelola Absensi**: Buat pertemuan dan input kehadiran

---

## 👥 4. KELOLA MAHASISWA

### 4.1 Melihat Daftar Mahasiswa
1. **Dari Dashboard**: Klik **"Mahasiswa"** pada mata kuliah tertentu
2. **Dari Jadwal**: Klik tombol **"Lihat Mahasiswa"** pada mata kuliah

### 4.2 Informasi Mahasiswa
Untuk setiap mahasiswa, ditampilkan:
- **Nama Lengkap**
- **NIM** (Nomor Induk Mahasiswa)
- **Program Studi**
- **Status Nilai**: Draft/Final (jika sudah ada penilaian)
- **Status KRS**: Disetujui (hanya mahasiswa yang KRS-nya disetujui yang muncul)

### 4.3 Aksi Cepat
- 📊 **Langsung ke Penilaian**: Klik nama mahasiswa untuk input nilai
- 📋 **Lihat Detail**: Informasi lengkap profil mahasiswa

---

## 📊 5. SISTEM PENILAIAN

### 5.1 Mengakses Halaman Penilaian
1. **Dari Dashboard**: Klik **"Penilaian"** pada mata kuliah
2. **Dari Jadwal**: Klik tombol **"Input Penilaian"**
3. **Dari Daftar Mahasiswa**: Klik nama mahasiswa

### 5.2 Komponen Penilaian

#### Input Nilai:
- **Nilai Tugas** (0-100): Nilai rata-rata tugas/assignment
- **Nilai UTS** (0-100): Nilai Ujian Tengah Semester
- **Nilai UAS** (0-100): Nilai Ujian Akhir Semester
- **Catatan**: Keterangan tambahan (opsional)

#### Bobot Penilaian (Default):
- **Tugas**: 30%
- **UTS**: 30% 
- **UAS**: 40%

### 5.3 Cara Input Penilaian

#### Input per Mahasiswa:
1. **Pilih Mahasiswa**: Klik pada baris mahasiswa
2. **Isi Komponen Nilai**:
   - Masukkan nilai tugas (0-100)
   - Masukkan nilai UTS (0-100)
   - Masukkan nilai UAS (0-100)
   - Tambahkan catatan jika diperlukan
3. **Simpan**: Klik tombol **"Simpan"** atau **"Update"**
4. **Nilai Akhir Otomatis**: Sistem akan menghitung nilai akhir, huruf, dan angka

#### Kalkulasi Otomatis:
- **Nilai Akhir** = (Tugas × 30%) + (UTS × 30%) + (UAS × 40%)
- **Konversi Huruf**:
  - A: 85-100
  - B+: 80-84
  - B: 75-79
  - C+: 70-74
  - C: 65-69
  - D: 60-64
  - E: 0-59

### 5.4 Status Penilaian
- **📝 Draft**: Nilai masih bisa diubah
- **🔒 Final**: Nilai sudah dikunci dan tidak bisa diubah

### 5.5 Finalisasi Nilai
1. **Pastikan Semua Nilai Sudah Diinput**
2. **Review Nilai**: Periksa kembali semua nilai mahasiswa
3. **Klik "Finalisasi Nilai"**: Semua nilai akan dikunci
4. **Konfirmasi**: Nilai final akan terkirim ke sistem akademik

### ⚠️ Penting:
- Setelah finalisasi, nilai **TIDAK BISA DIUBAH**
- Pastikan semua nilai sudah benar sebelum finalisasi
- Hubungi admin jika perlu mengubah nilai yang sudah final

---

## ✅ 6. KELOLA ABSENSI

### 6.1 Mengakses Absensi
1. **Dari Dashboard**: Klik **"Absensi"** pada mata kuliah
2. **Dari Jadwal**: Klik tombol **"Kelola Absensi"**

### 6.2 Membuat Pertemuan Baru

#### Langkah Buat Pertemuan:
1. **Klik "Buat Pertemuan"** atau **"Tambah Pertemuan"**
2. **Isi Data Pertemuan**:
   - **Tanggal**: Pilih tanggal perkuliahan
   - **Jam Mulai**: Waktu mulai kuliah (format HH:MM)
   - **Jam Selesai**: Waktu selesai kuliah (format HH:MM)
3. **Simpan**: Klik **"Buat Pertemuan"**
4. **Sistem Otomatis**: Membuat record absensi untuk semua mahasiswa (default: tidak hadir)

#### ⚠️ Validasi:
- Tidak bisa membuat pertemuan dengan tanggal yang sama
- Jam selesai harus lebih besar dari jam mulai
- Hanya bisa membuat pertemuan untuk periode aktif

### 6.3 Input Absensi Mahasiswa

#### Cara Input Absensi:
1. **Pilih Pertemuan**: Klik pada tanggal pertemuan yang sudah dibuat
2. **Daftar Mahasiswa**: Akan muncul tabel dengan semua mahasiswa
3. **Update Status per Mahasiswa**:
   - ✅ **Hadir**: Mahasiswa mengikuti perkuliahan
   - ❌ **Tidak Hadir**: Tidak mengikuti tanpa keterangan
   - 📝 **Izin**: Tidak hadir dengan izin resmi
   - 🏥 **Sakit**: Tidak hadir karena sakit
4. **Tambahkan Keterangan**: Catatan tambahan (opsional)
5. **Simpan Semua**: Klik **"Update Absensi"** atau **"Simpan"**

#### Fitur Cepat:
- **Pilih Semua Hadir**: Tandai semua mahasiswa hadir sekaligus
- **Reset**: Kembalikan ke status default
- **Filter Status**: Tampilkan berdasarkan status kehadiran

### 6.4 Kelola Pertemuan

#### Edit Pertemuan:
- **Ubah Waktu**: Edit jam mulai/selesai jika diperlukan
- **Update Status**: Ubah status kehadiran mahasiswa

#### Hapus Pertemuan:
1. **Pilih Pertemuan**: Klik pada pertemuan yang ingin dihapus
2. **Klik "Hapus Pertemuan"**
3. **Konfirmasi**: Semua data absensi pertemuan akan terhapus

### 6.5 Rekap Absensi

#### Mengakses Rekap:
1. Dari halaman absensi, klik **"Rekap Absensi"**
2. Sistem menampilkan statistik kehadiran per mahasiswa

#### Informasi Rekap per Mahasiswa:
- **Total Pertemuan**: Jumlah pertemuan yang sudah dibuat
- **Jumlah Hadir**: Berapa kali mahasiswa hadir
- **Jumlah Tidak Hadir**: Absen tanpa keterangan
- **Jumlah Izin**: Tidak hadir dengan izin
- **Jumlah Sakit**: Tidak hadir karena sakit
- **Persentase Kehadiran**: Dihitung dari total hadir/total pertemuan

#### Ekspor/Cetak:
- **Print Rekap**: Cetak laporan kehadiran
- **Download**: Unduh dalam format yang sesuai

### ⚠️ Batasan Minimum Kehadiran:
- Biasanya mahasiswa harus hadir minimal **75%** dari total pertemuan
- Jika di bawah batas minimum, mahasiswa tidak bisa mengikuti ujian
- Gunakan rekap untuk monitoring kehadiran

## ❓ 9. TROUBLESHOOTING & FAQ

### Masalah Umum:

#### Q: Tidak bisa login?
**A:** 
- Pastikan email/username dan password benar
- Hubungi admin jika akun belum diaktivasi
- Clear browser cache dan cookies

#### Q: Tidak ada mata kuliah di jadwal?
**A:**
- Mungkin belum ada periode aktif
- Jadwal belum diinput oleh admin
- Status dosen belum aktif - hubungi admin

#### Q: Mahasiswa tidak muncul di daftar kelas?
**A:**
- Mahasiswa belum mengambil KRS mata kuliah Anda
- KRS mahasiswa belum disetujui admin
- Mahasiswa mungkin sudah membatalkan mata kuliah

#### Q: Tidak bisa input nilai?
**A:**
- Pastikan periode masih aktif
- Data mahasiswa sudah final (KRS disetujui)
- Periksa format input nilai (0-100)

#### Q: Error saat buat pertemuan absensi?
**A:**
- Cek format tanggal dan jam
- Pastikan tidak ada pertemuan di tanggal yang sama
- Jam selesai harus lebih besar dari jam mulai

#### Q: Nilai sudah final, tapi perlu diubah?
**A:**
- Hubungi admin akademik
- Sertakan alasan perubahan nilai
- Admin yang akan membuka kembali status nilai

#### Q: Rekap absensi tidak sesuai?
**A:**
- Periksa apakah semua pertemuan sudah diinput
- Cek status absensi per pertemuan
- Refresh halaman atau logout-login kembali

## ✅ 11. TIPS PENGGUNAAN OPTIMAL

### Untuk Pengalaman Terbaik:
1. **Browser yang Disarankan**:
   - Google Chrome (terbaru)
   - Mozilla Firefox (terbaru)
   - Microsoft Edge (terbaru)

2. **Koneksi Internet**:
   - Pastikan koneksi internet stabil
   - Speed minimal 1 Mbps untuk akses lancar

3. **Workflow yang Efisien**:
   - **Mingguan**: Input absensi setiap selesai kuliah
   - **Tengah Semester**: Input nilai tugas dan UTS
   - **Akhir Semester**: Input nilai UAS dan finalisasi
   - **Berkala**: Monitor rekap absensi mahasiswa

4. **Backup Data**:
   - Screenshot rekap nilai sebelum finalisasi
   - Catat persentase kehadiran mahasiswa
   - Simpan catatan penting di luar sistem

5. **Komunikasi dengan Mahasiswa**:
   - Informasikan deadline input nilai
   - Berikan feedback melalui catatan penilaian
   - Pantau kehadiran dan beri peringatan jika perlu
